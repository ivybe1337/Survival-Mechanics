ARC-AGI-2 · official public-evaluation run

Where the accuracy goes

The generator is the open NVARC pipeline (Qwen3-4B with per-task test-time training), unchanged. Each test output gets a pool of decoded candidates and two attempts. Every number in this section comes from notebook Version 1, the full 120-task public-evaluation run of the linked submission. Accuracy factors exactly: how often a test output received a pool at all, how often the right answer was generated, and how often selection then put it in the top two.

Selection rules, replayed on identical pools

Every count is recomputed from the 157 per-output records. The rules were pre-registered before any pool was read. V4 breaks the rule on purpose: it deletes candidates whose likelihood trails the best by more than ln 10.

The one fix · task 2b83f449

13 of 14 candidates broke a law the demonstrations obey

In every demonstration the output uses exactly the same multiset of colour counts as the input. Most candidates the model proposed for the test did not, so the ledger moved them behind the admissible ones and the true answer rose from third place to first. The grids and colour profiles below are computed live from the public task.

Mechanism

Local laws are absorbed. Global ones are not.

Which invariants ever catch a wrong candidate

An invariant is active on an output only if it holds on every demonstration of that task.

My reading: a generator fitted to the demonstrations learns what a cell-by-cell decoder can enforce, and does not learn global counting, which no single cell can see.
